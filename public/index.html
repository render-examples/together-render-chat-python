How this works

Python FastAPI on Render. This page sends the thread to POST /ui/chat. API clients use bearer CHAT_API_KEY on single-turn POST /chat. 

curl -X POST "$SERVICE_URL/chat" \
  -H "Authorization: Bearer $CHAT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"message":"Hello"}'
