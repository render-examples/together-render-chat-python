How this works

Python FastAPI on Render. This page calls POST /ui/chat with the service env. External clients still use bearer CHAT_API_KEY on POST /chat. 

curl -X POST "$SERVICE_URL/chat" \
  -H "Authorization: Bearer $CHAT_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{"message":"Hello"}'
